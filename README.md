# IRUAV-DETR

Official PyTorch implementation of IRUAV-DETR.

---

## ⚙️ Requirements

- Python 3.10  
- PyTorch 2.0.1 (CUDA 11.8)   
- opencv-python  
- numpy  
- scikit-image  
---

## 📂 Dataset

We use the following datasets:

### HIT-UAV
- Download: https://github.com/suojiashun/HIT-UAV-Infrared-Thermal-Dataset  
---
## 🚀 Training & Testing

### Training
python train.py

You can modify training configurations in train.py, including:

- dataset path
- batch size
- number of epochs

### Testing
python test_xxx.py
